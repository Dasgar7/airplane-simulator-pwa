# Airplane Simulator

Playable 3D open-world PWA. Fly a plane between country islands, pick up passengers who need to travel, and get paid.

## Play

- Desktop: WASD / arrows, Shift throttle, Space land, E pick up / drop off, J jobs
- Phone: landscape recommended. Left stick steer, right stick throttle, Jobs / Land / Pick Up

## Install

Use the browser Install App prompt (PWA / Add to Home Screen).
